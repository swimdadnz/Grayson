Copy these two files into assets/ using those exact names (including spaces and capitalisation).

Record recency heat maps use the build date as the as-at date. '0-1y' means a record set within
one year before this date. A record tied later is counted once at the original date first achieved.
Unclaimed Standard benchmarks and undated entries do not contribute to the heat maps.

The private Excel workbook stays PRIVATE and must not be uploaded to the public GitHub repository.
To repopulate recency after a new record-book update, regenerate from the new master workbook.
